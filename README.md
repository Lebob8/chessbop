# ChessBop Frontend

Chess analysis board with Stockfish WASM.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start

# Lint code
npm run lint

# Format code
npm run format
```

## 🛠 Tech Stack

- **Next.js 16** (App Router)
- **React 19** + TypeScript
- **Tailwind CSS v4** (with PostCSS plugin)
- **ESLint** + **Prettier**
